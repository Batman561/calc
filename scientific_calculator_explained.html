شروعکامنت‌ها و import

پایتون فایل را از بالا به پایین، خط به خط می‌خواند. اول کار، ابزارهایی را که لازم داریم وارد می‌کنیم.

1# ════════════════════════════════════════════════════════════2#   ماشین حساب مهندسی با پایتون (نسخه‌ی دوم)3#   همان ماشین حسابِ ساده، به‌علاوه‌ی توابع و ثابت‌های مهندسی4#   برای اجرا، در ترمینال این دستور را بزنید:5#       python scientific_calculator.py6# ════════════════════════════════════════════════════════════

هر خطی که با # شروع شود یک کامنت (یادداشت) است. پایتون آن را نادیده می‌گیرد؛ فقط برای آدم‌ها نوشته شده. این‌جا بالای فایل نوشته‌ایم این برنامه چیست و چطور اجرا می‌شود: نسخه‌ی مهندسیِ ماشین‌حساب، که همه‌ی امکانات نسخه‌ی ساده را دارد به‌علاوه‌ی مثلثات، لگاریتم، جذر، فاکتوریل و ثابت‌هایی مثل عدد پی. خط‌های ═ فقط تزئینی‌اند.

8# ماژول os را می‌آوریم تا صفحه‌ی ترمینال را پاک کنیم و با فایل‌ها کار کنیم9import os

کلمه‌ی import یعنی «بیاور». پایتون جعبه‌ابزارهای آماده‌ای به اسم ماژول دارد. os (مخفف Operating System یعنی سیستم‌عامل) جعبه‌ابزاری برای کار با سیستم‌عامل است؛ بعداً از آن برای پاک کردن صفحه‌ی ترمینال و پیدا کردن آدرس فایل تاریخچه استفاده می‌کنیم. تا ماژولی را import نکنیم، نمی‌توانیم از ابزارهایش استفاده کنیم.

11# ماژول math جعبه‌ابزارِ ریاضیِ پایتون است: سینوس، لگاریتم، جذر، عدد پی و...12import math

ماژول math جعبه‌ابزار ریاضی پایتون است و این نسخه زیاد از آن استفاده می‌کند: math.sin و math.cos برای مثلثات، math.sqrt برای جذر، math.log10 و math.log برای لگاریتم، math.pi و math.e برای ثابت‌ها، math.factorial برای فاکتوریل، و math.isfinite برای فهمیدن اینکه عدد بی‌نهایت شده یا نه.

بخش ۱رنگ‌ها، ظاهر و منو

ترمینال با دیدن رشته‌های مخصوصی به اسم کد ANSI، رنگ متن بعدی را عوض می‌کند. در این بخش این کدها، لوگو و داده‌های منو را در متغیرها آماده می‌کنیم. هنوز چیزی چاپ نمی‌شود.

19# این رشته‌های عجیب «کد رنگ» هستند. ترمینال آن‌ها را چاپ نمی‌کند؛20# بلکه با دیدنشان، رنگ یا حالتِ متنِ بعدی را عوض می‌کند.21RESET = "\033[0m"

این یک متغیر است. متغیر مثل یک جعبه‌ی برچسب‌دار است: اسم جعبه RESET است و علامت = یعنی «این مقدار را داخل جعبه بگذار» (نه «مساوی است» در ریاضی!). مقدار داخلش یک رشته (متن) است، چون بین دو علامت " قرار گرفته.

\033 یک کاراکتر نامرئی به اسم Escape است و [0m به ترمینال می‌گوید «همه‌ی رنگ‌ها و حالت‌ها را به حالت عادی برگردان». بعد از رنگی کردن هر متن، RESET می‌زنیم تا رنگ به بقیه‌ی متن‌ها سرایت نکند. اسم متغیر را با حروف بزرگ نوشته‌ایم؛ این یک قرارداد در پایتون است برای مقدارهایی که قرار نیست عوض شوند (ثابت‌ها).

پایین‌ترین طبقه: جمع و تفریق. چرا پایین‌ترین؟ چون جمع و تفریق کمترین اولویت را دارند و آخر از همه انجام می‌شوند. این تابع لیست توکن‌ها را می‌گیرد، از ابتدایش توکن مصرف می‌کند و یک عدد جواب برمی‌گرداند.

313        if operator == "*":

اگر ضرب بود...

...* علامت ضرب در پایتون است.

315        elif operator == "/":

322def parse_unary(tokens):
