دکمه‌ها

در ترمینال نمی‌شود با ماوس روی دکمه کلیک کرد؛ پس «دکمه»ها کلیدهایی‌اند که تایپ می‌کنید و بعد Enter می‌زنید:

H نمایش تاریخچه‌ی همه‌ی حساب‌ها؛ حتی از دفعه‌های قبل (در فایل history.txt ذخیره می‌شود)
D پاک کردن کل تاریخچه (اول تأیید می‌گیرد)
M نمایش دوباره‌ی منوی علامت‌ها (با مثال)
C پاک کردن صفحه
Q خروج

▶️چطور اجرایش کنم؟

  1. پایتون را از python.org دانلود و نصب کنید. موقع نصب حتماً تیک Add python.exe to PATH را بزنید.
  2. فایل calculator.py را در یک پوشه بگذارید.
  3. در File Explorer داخل همان پوشه راست‌کلیک کنید و Open in Terminal را بزنید.
  4. این دستور را بنویسید و Enter بزنید: python calculator.py
  5. یک عبارت مثل (2 + 3) * 4 تایپ کنید و Enter بزنید. برای دیدن تاریخچه h، برای پاک کردنش d، برای دیدن منوی علامت‌ها m و برای خروج q.
چرا متن‌های داخل برنامه انگلیسی است؟ ترمینال‌ها هنوز نوشته‌های راست‌به‌چپ (مثل فارسی) را درست نشان نمی‌دهند و حروف به‌هم‌ریخته و برعکس دیده می‌شوند. برای همین متن‌هایی که روی صفحه می‌آیند انگلیسی‌اند، ولی همه‌ی کامنت‌های داخل کد فارسی‌اند. (ضمناً اعداد فارسی مثل ۲ + ۳ را هم می‌فهمد!) برای بهترین ظاهر از Windows Terminal (ترمینال پیش‌فرض ویندوز ۱۱) استفاده کنید.

def double(x):

if x > 0: ...
elif x == 0: ...
else: ...

«اگر... وگرنه اگر... وگرنه». == یعنی «آیا برابر است؟» و != یعنی «آیا نابرابر است؟».

🔁حلقه

while i < 10: ...
for x in items: ...

while: «تا وقتی شرط درست است تکرار کن». for: «برای تک‌تک اعضا تکرار کن». break از حلقه بیرون می‌پرد.

if ok:
    print("yes")  # inside

🛟مدیریت خطا

try: ...
except ValueError: ...
raise ValueError("oops")

try تور ایمنی است؛ اگر خطا شد، except آن را می‌گیرد. raise عمداً خطا پرتاب می‌کند.

رنگ‌ها و ظاهر برنامه

ترمینال در حالت عادی فقط متن ساده‌ی سفید نشان می‌دهد. اما یک راز دارد: اگر رشته‌های مخصوصی به اسم کد ANSI را چاپ کنیم، ترمینال آن‌ها را نشان نمی‌دهد و به جایش رنگ متنِ بعدی را عوض می‌کند. در این بخش این کدها را در متغیرهایی با اسم‌های خوانا (مثل GREEN) نگه می‌داریم تا بعداً راحت از آن‌ها استفاده کنیم.

این یک متغیر است. متغیر مثل یک جعبه‌ی برچسب‌دار است: اسم جعبه RESET است و علامت = یعنی «این مقدار را داخل جعبه بگذار» (نه «مساوی است» در ریاضی!). مقدار داخلش یک رشته (متن) است، چون بین دو علامت " قرار گرفته.

\033 یک کاراکتر نامرئی به اسم Escape است و [0m به ترمینال می‌گوید «همه‌ی رنگ‌ها و حالت‌ها را به حالت عادی برگردان». بعد از رنگی کردن هر متن، RESET می‌زنیم تا رنگ به بقیه‌ی متن‌ها سرایت نکند. اسم متغیر را با حروف بزرگ نوشته‌ایم؛ این یک قرارداد در پایتون است برای مقدارهایی که قرار نیست عوض شوند (ثابت‌ها).
