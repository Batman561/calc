# 🧮 ماشین‌حساب مهندسی ترمینالی با پایتون

**یک ماشین‌حساب مهندسی خوش‌ظاهر برای ترمینال، همراه با آموزش خط به خط کد به زبان فارسی**

<br>

![Python](https://img.shields.io/static/v1?label=Python&message=3.8%2B&color=3776AB&logo=python&logoColor=white)
![Dependencies](https://img.shields.io/static/v1?label=Dependencies&message=None&color=2ea44f)
![Docs](https://img.shields.io/static/v1?label=Docs&message=Persian&color=8957e5)

<br>

ترمینال لازم نیست خشک و بی‌روح باشد. این پروژه یک ماشین‌حساب مهندسی است که در ترمینال اجرا می‌شود، با لوگوی رنگی، کادرهای مرتب، دکمه‌های میان‌بُر، تاریخچه‌ای که با بستن برنامه پاک نمی‌شود، و پیام‌های خطایی که واقعاً می‌گویند مشکل کجاست.

نکته‌ی اصلی اما چیز دیگری است: کنار کد، یک صفحه‌ی آموزشی هست که **تک‌تک خط‌ها** را به زبان ساده توضیح می‌دهد. یعنی هم یک ابزار کاربردی دارید و هم یک کلاس کوچک پایتون. ✨

## 🚀 شروع سریع

فقط کافی است **پایتون ۳.۸ یا جدیدتر** روی سیستم‌تان نصب باشد. هیچ کتابخانه‌ی اضافه‌ای لازم نیست. اگر پایتون ندارید، از [python.org](https://www.python.org/downloads/) دانلودش کنید.

```bash
git clone https://github.com/Batman561/calc.git
cd calc
python calculator.py
```

در مک و لینوکس اگر `python` کار نکرد، `python3` را امتحان کنید.

## 💡 چند نکته

* بهترین ظاهر را در **Windows Terminal** (ترمینال پیش‌فرض ویندوز ۱۱) یا هر ترمینال مدرن دیگری می‌بینید.
* نوشته‌های داخل برنامه انگلیسی‌اند، چون ترمینال‌ها هنوز متن فارسی را درست نشان نمی‌دهند.
* اعداد فارسی هم کار می‌کنند؛ مثلاً `۲ + ۳`.
* تاریخچه در فایل `scientific_history.txt` کنار خود برنامه ذخیره می‌شود.
